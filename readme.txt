A collection of Gutenberg blocks for creating clear, structured technical documentation in WordPress.

== Description ==

Developer Docs Blocks is an open-source WordPress plugin focused on improving the authoring of technical documentation with native Gutenberg blocks.

Planned blocks include:

* Code Example: For displaying code snippets.
* Callout:      For highlighting notes, tips, and warnings.
* Steps:        For presenting instructions in sequence.
* Requirements: For documenting prerequisites and compatibility.

The initial release is under development. Features listed above are planned and may not yet be available.

== Installation ==

1. Upload the plugin files to the `/wp-content/plugins/developer-docs-blocks` directory, or install the packaged ZIP through the WordPress Plugins screen.
2. Activate Developer Docs Blocks through the WordPress Plugins screen.
3. Open the block editor and insert a block provided by the plugin once that block is available.
